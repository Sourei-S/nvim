# vim 練習メニュー & チートシート

vim_practice.py(ダミーコード)を素材にしたお題集。壊して OK、戻すのは `u` か `:e!`。
キー操作はノーマルモードから。`⏎` は Enter、`␣` は半角スペース。

## お題(順不同で好きなものから)

| # | お題 | 使う操作 | 場所の目安 |
|---|------|---------|-----------|

| 3 | 製品名をひとつ書き換える | `ciw` / `ci"` | products |
| 4 | stock の数値を増減する | 数字にカーソル → `Ctrl-a` / `Ctrl-x` | products |
| 5 | 価格の列だけ矩形選択して削る → 戻す | `Ctrl-v` `j`... `l`... → `d` → `u` | products(列が揃っている) |

## 最小チートシート

| 分類 | キー | 意味 |
|------|------|------|
| モード | `i` / `a` / `o` / `Esc` | カーソル前・後・下の新行で挿入 / ノーマルへ戻る |
| 保存終了 | `:w` / `:q` / `:wq` / `:q!` | 保存 / 終了 / 保存して終了 / 破棄して終了 |
| 取り消し | `u` / `Ctrl-r` | undo / redo |
| 移動 | `w` `b` `e` `0` `$` `gg` `G` | 単語単位 / 行頭・行末 / ファイル先頭・末尾 |
| 検索 | `/word⏎` `n` `N` | 検索 / 次の一致へ / 前の一致へ |
| 削除・複製 | `x` `dd` `yy` `p` | 1 文字削除 / 行削除 / 行コピー / 貼り付け |
| 中身の書き換え | `ci(` / `ci"` / `ciw` | カッコ / クォート / 単語の中身を消して挿入モードへ |
| 中身の選択 | `vi(` / `vi"` / `viw` | 中身を選択だけする。範囲を目で確認してから `c` で書き換え |
| N 個目を狙う | `2f(` → `ci(` | 行内 2 つ目の `(` へ飛んでから中身を書き換え。`f(` `;` でも同じ |
| 画面分割 | `:vs` / `:sp` | 左右 / 上下に分割。`:vs ファイル名` で別ファイル、起動時なら `nvim -O a b` |
| 分割の操作 | `Ctrl-w` + `h j k l` / `o` / `=` | 分割間を移動 / 今の場所以外を全部閉じる / 幅を均等化 |
| 実行 | `:w` → `:!python3 %` | 保存してから、開いているファイルを実行してみる(このダミーは一応動く) |

※ 行頭からいきなり `ci(` と打つと「1 つ目」のカッコに飛ぶ。「2 つ目」を狙うなら `2f(` で先に移動してから。
※ まぎらわしいが `2ci(` は入れ子カッコの「2 段外側」の意味で、「2 つ目に出現」ではない。

散らかしすぎて戻れなくなったら、保存せず `:q!` で閉じれば直前の保存状態が残る。
それでもダメなら、このファイル一式を再ダウンロードすればやり直せる。
